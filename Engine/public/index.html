🔑 Set your admin passphrase

The admin passphrase is a Cloudflare secret on your own Worker. Nobody else can read it — not us, not Cloudflare support. It unlocks Under the hood, where you edit this bot’s greeting, its starter questions, its documents and its rules.

In your browser, no terminal needed:

  1. Open the Cloudflare dashboard and go to Workers & Pages.
  2. In Overview, select this Worker, then Settings.
  3. Under Variables and Secrets, select Add.
  4. Choose type Secret, name it ADMIN_PASSPHRASE, and type the passphrase you want.
  5. Select Deploy, then come back here and reload this page.

Or, from a terminal:

printf 'your admin code' | npx wrangler secret put ADMIN_PASSPHRASE

You can’t read a secret back once it is set — only replace it. Write it down somewhere before you press Deploy. The same steps set ACCESS_PASSPHRASE, the one that gates visitors, if you want a locked bot rather than a sign-up.
